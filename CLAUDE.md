# Claude Code workflow

Follow [`AGENTS.md`](AGENTS.md) and the canonical pull-request runbook at
[`docs/runbooks/pull-requests.md`](docs/runbooks/pull-requests.md).

A completed versioned task normally ends with its branch pushed and a pull
request opened or updated against `develop`. Creating the PR is authorized;
merging, approving, closing, retargeting, or promoting it to `main` is not unless
the owner explicitly requests that action.
